🏝️
島レベルと開放エリア

タスクを達成して経験値(EXP)を溜めることで、島レベルが上昇します (最大 Lv.99)。

レベルアップによる恩恵
  • 島の土地拡大: レベルが上がると3Dアイランドの敷地（グラウンドサイズ）が段階的に大きくなります。
  • 配置可能エリアの解禁:
    • 🌱 陸地エリア : Lv.1 から配置可能
    • 🌊 海洋エリア : Lv.20 で開放（ヨット・手漕ぎボート・水上コテージ等）
    • ☁️ 上空エリア : Lv.50 で開放（気球・浮遊島・虹の架け橋等）
  • 称号や各種実績の獲得: 特定の島レベル達成により特別な実績や称号が解放されます。
⭐
島経験値 (EXP) の獲得方法

日常の業務タスクを完了することで島経験値を獲得できます。

EXP獲得条件
タスク完了 (Status: 完了 / Closed) +10 EXP
※ 1つのタスクにつき1度のみ付与されます。
レベルアップに必要な目安

Lv.1 (0 EXP) → Lv.2 (50 EXP) → Lv.3 (120 EXP) → Lv.4 (220 EXP) → Lv.5 (350 EXP) ... と必要EXPが少しずつ増えていきます。

🪙
コインの獲得方法と使い道

コインは島を装飾するアイテムをショップで購入するために使用します。

獲得方法

タスクを完了すると、EXPと同時に +5 コイン が進呈されます。

使い道 (ショップ)

3Dキャンバス内の「所持品 / ショップ」パネルのショップタブから、好きな樹木・建物・動物・海洋アイテムなどを直接コインで購入できます。

🎟️
ガチャチケットの入手方法と使い方

特別・レアな島アイテムや動物を無料でランダム入手できるチケットです。

入手方法

タスクを 5件完了するごと に ガチャチケット ×1枚 が自動的にプレゼントされます。

使い方

画面右上の「ガチャを引く」ボタンからガチャページへアクセスし、チケット1枚につき1回ガチャを回せます。獲得したアイテムは所持品ボックスへ入ります。

基本操作 & プレイのアドバイス

  • 回転 (Orbit): マウス左ドラッグ（またはスワイプ）で島を全方位360度見回せます。
  • ズーム (Zoom): マウスホイールスクロール（またはピンチイン/アウト）で拡大・縮小ができます。
  • 移動 (Pan): マウス右ドラッグでカメラの位置を平行移動できます。

  • 画面右下の「所持品 / ショップ」ボタンをクリックするとインベントリパネルが開きます。
  • 配置・片付け: アイテムカードの「配置」/「しまう」ボタンで島に飾るかしまうかを切替えられます。
  • 位置・向きの変更: 「配置中」タブで各アイテムの X/Z 座標および Y軸回転角度を調整し、「位置変更を保存」を押すことで好みのレイアウトにカスタマイズ可能です。

配置されたシバイヌ、三毛猫、ウサギ、ペンギン、カピバラ、イルカ、ウミガメなどの生き物は、島の地形標高にあわせて自然に島内を歩き回ったり泳いだりします！生き生きとした島の様子をお楽しみください。
